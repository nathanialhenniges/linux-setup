2

Boot the USB and test internet

Do this in the live session before opening the installer.

iPhone → cable → MacBook Air → working webpage

Internal Broadcom Wi-Fi may need its driver after installation. Confirm the live USB has another working internet route first.

  1. Start the Mac while holding Option (⌥). Choose the USB’s EFI entry.
  2. Unlock the iPhone, connect it, then turn on Settings → Personal Hotspot → Allow Others to Join. Tap Trust if asked.
  3. Open a browser in the live session and load a webpage.
If the page will not load, stop here. iPhone USB tethering may need packages the live USB does not have. Use USB Ethernet or another known-working connection first. Do not erase the disk yet.

Install EndeavourOS

4

Copy, paste, and run setup

Use Ghostty or another terminal. Run commands as your normal account, not root.

If Git is missing

sudo pacman -Syu --needed git

Download the setup repo

mkdir -p ~/Developer
cd ~/Developer
git clone https://github.com/nathanialhenniges/linux-setup.git
cd linux-setup

Install Ansible, then check readiness

./setup.sh bootstrap
./setup.sh status

If the first command reports a problem, stop and read the message.

Preview the full plan

./setup.sh --dry-run all

Read the plan before continuing. Dry run makes no changes and does not use sudo or the network.

Run the setup

./setup.sh all

Review the AUR build prompts. Setup does not auto-approve them. Chrome, VS Code, and built-in camera support use AUR packages.

Then reboot:

reboot
5

First login and quick checks

Choose Hyprland at login. The Mac’s Command key acts as Super.

Verify the laptop setup

cd ~/Developer/linux-setup
./setup.sh verify
6

Connect to your Mac with Chrome Remote Desktop

This laptop is the client. It does not install a Chrome Remote Desktop host.

Hyprland uses Super shortcuts locally. Remote Mac mode pauses those while you work on the remote Mac. It helps prevent local shortcuts from consuming Command-key combinations, but Chrome Remote Desktop controls the final key translation.

Open CRD

Google’s CRD help · Hyprland key-binding modes

If you only remember three things

  1. 1. Test internet in the live USB before erasing the disk.
  2. 2. Read the dry-run plan before running the full setup.
  3. 3. Test Mac Command shortcuts in a real Chrome Remote Desktop session.
